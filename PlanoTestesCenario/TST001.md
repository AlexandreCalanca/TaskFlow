## TST001 – Criação de quadro bem-sucedida

**Caso de uso em que se baseia:** DCU002 – Criar Quadro

**Cenário:** Fluxo Principal

**Preparação:**

a) A aplicação TaskFlow deverá estar disponível para acesso.

b) Os seguintes quadros deverão estar cadastrados no sistema:

| Nome do quadro |
|----------------|
| Projeto Faculdade |
| Desenvolvimento Web |
| Atividades Pessoais |

c) O usuário deverá possuir acesso à funcionalidade de criação de quadros.

**Passos para execução:**

1. Acessar a página inicial da aplicação TaskFlow.
2. Selecionar a opção de criar um novo quadro.
3. Informar "Projeto Engenharia de Software" como nome do quadro.
4. Confirmar a criação do novo quadro.
5. Verificar a lista de quadros disponíveis.
6. Selecionar o quadro criado.

**Resultado esperado:**

a) O sistema deverá cadastrar o quadro "Projeto Engenharia de Software" com sucesso.

b) A lista de quadros deverá apresentar os seguintes registros:

| Nome do quadro |
|----------------|
| Projeto Faculdade |
| Desenvolvimento Web |
| Atividades Pessoais |
| Projeto Engenharia de Software |

c) O quadro criado deverá apresentar automaticamente as seguintes colunas:

| Ordem | Nome da coluna |
|-------|----------------|
| 1 | A Fazer |
| 2 | Em Progresso |
| 3 | Concluído |

**Resultado do teste:**

( ) Sucesso
( ) Não executado
( ) Falha
( ) Cancelado
